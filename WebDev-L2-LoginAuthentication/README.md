# 🔐 Login Authentication System

A simple login and registration web app built with HTML, CSS, and JavaScript. It provides a clean authentication UI with client-side validation and local storage-based user handling.

## ✨ Features

- Switch between login and registration forms
- Register a new user with validation
- Login using stored credentials
- Show or hide password input
- Display success and error messages dynamically
- Store user data locally in the browser using localStorage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run

1. Open the project folder.
2. Launch the `index.html` file in your browser.
3. Register a new account and then log in.

## 📁 Project Structure

- `index.html` – Main UI for login and registration forms
- `style.css` – Styling and layout for the authentication page
- `script.js` – Form switching, validation, login logic, and password toggle

## 💡 Usage

- Click **Register** to create a new account.
- Enter a valid email and a password of at least 6 characters.
- Use the eye icon to show or hide the password.
- After registration, switch to the login form and sign in.
