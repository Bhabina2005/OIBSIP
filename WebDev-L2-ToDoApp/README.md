# 📝 To-Do Web App

A simple and elegant To-Do list application built with HTML, CSS, and JavaScript. It allows users to add, edit, complete, and delete tasks while tracking the total, completed, and pending counts.

## ✨ Features

- Add new tasks quickly
- Mark tasks as completed
- Edit existing tasks
- Delete tasks from the list
- View real-time task statistics
- Responsive layout for mobile and desktop screens

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run

1. Open the project folder in your browser.
2. Open the `index.html` file.
3. Start managing your tasks.

## 📁 Project Structure

- `index.html` – Main structure of the app
- `style.css` – Styling and responsive design
- `script.js` – Task management logic

## 💡 Usage

- Type a task in the input box and click **Add**.
- Use the **✔** button to mark a task as completed.
- Use the **✏** button to edit a task.
- Use the **🗑** button to remove a task.
